## OSD-679 Paper Experimental Protocol (Repo-Ready Version)

This is a manuscript execution plan adapted to the current `RETFoundLoRA` codebase and CLI.

It is based on the OSD-679 study framing (Controls for normative aging, HLS as out-of-distribution stress condition) and maps the draft protocol to **runnable commands** where supported today.

### Dataset Scope (paper reference)
- Species: Brown rat (`Rattus norvegicus`)
- Modality: SD-OCT B-scans (`BScanThumb`, `REGAVG`)
- Conditions: `Controls`, `HLS (U)`
- Cohorts: `1`, `2`, `3` (exclude cohort `4`)
- Primary days: `0`, `90`
- Targets: age regression, `RAG = age_pred - age_true`
- Split policy: rat-level splits (already implemented in `RETFoundLoRA/run.py`)

### Current Best Setups (as of this protocol package)

#### Control-priority RETFound setup
- MAE-transductive adapted RETFound backbone
- `MIL + LoRA` (`lora_blocks=4`)
- `aug_level=mild`, `--no-photometric-aug`
- `--day-whitelist 0 90`
- `--control-eval-days 0 90`
- `--cohorts 1 2 3`
- `--lr 1e-4`, `--epochs 40`

#### Strong Xception baseline (control day 0/90)
- `--model-type xception`
- `--day-whitelist 0 90`
- `--control-eval-days 0 90`
- `--cohorts 1 2 3`
- `--aug-level mild --no-photometric-aug`
- `--lr 1e-3`, `--epochs 40`

### Support Status (draft EXP-01..12 vs current code)

`ready`
- EXP-01: Normative aging baseline (control-only), including CV via `--kfolds`
- EXP-02: HLS OOD evaluation (directly from per-run HLS prediction exports; no separate `eval_ood.py` required)
- EXP-03: Inter-eye reliability analysis (paired CSVs + new `scripts/compute_inter_eye_mad.py`)
- EXP-04: Saliency exports (via `scripts/save_saliency_subset.py`)
- EXP-05: Backbone ablation (RETFound vs Xception; random ViT not implemented)
- EXP-08: Bias correction sensitivity (with/without correction)
- EXP-09: Timepoint robustness (all timepoints / all ages)
- EXP-10: Sex-stratified analysis (new `scripts/stratify_by_sex.py`)
- EXP-11: Feature distillation (Xception + frozen RETFound teacher, feature-only)
- EXP-12: RAG-physiology correlation (new `scripts/correlate_rag_physiology.py`)

`partial / requires code extension`
- EXP-06: LoRA vs full fine-tuning vs no adaptation
  - Supported: frozen MIL baseline vs MIL+LoRA
  - Not fully supported in a clean CLI way: full RETFound fine-tuning in MIL path without PEFT
- EXP-07: Cohort leave-one-out (LOCO)
  - Current `--cohorts` filter is global. True train-cohort/test-cohort separation needs separate train/test cohort filters or custom split injection.

### Core Commands (current CLI)

#### EXP-01: Control-only CV (RETFound, normative baseline)
Run:
```bash
bash scripts/paper/run_all_core_experiments.sh exp01_ctrl_cv
```

This script uses:
- rat-level CV: `--kfolds 3 --run-all-folds`
- control-only training: `--train-groups Controls`
- HLS as held-out test export: `--test-groups "HLS (U)"`

Outputs (default location):
- `outputs/core/exp01_ctrl_cv/...`
- `summary.csv` generated by `scripts/aggregate_cv.py`

#### EXP-02: HLS OOD evaluation (from EXP-01 fold outputs)
Run:
```bash
bash scripts/paper/run_all_core_experiments.sh exp02_hls_ood
```

This aggregates HLS/stress metrics and cohort/day breakdowns across EXP-01 fold runs.

#### EXP-03: Inter-eye reliability
Run:
```bash
bash scripts/paper/run_all_core_experiments.sh exp03_inter_eye
```

#### EXP-04: Saliency examples
Run:
```bash
bash scripts/paper/run_all_core_experiments.sh exp04_saliency
```

Notes:
- Uses `scripts/save_saliency_subset.py` (already in repo), not a non-existent `RETFoundLoRA/export_saliency.py`.

### Ablations / Extensions

#### EXP-05: Backbone ablation
Run:
```bash
bash scripts/paper/run_backbone_ablation.sh
```

Current script supports:
- RETFound (configured baseline)
- Xception

Random ViT row is marked as unsupported until a third backbone option is added to `run.py`.

#### EXP-08: Bias correction sensitivity
Use the same trained checkpoints and compare eval with:
- `--bias-correction` (default on), versus
- `--no-bias-correction`

#### EXP-09: All-timepoint exploratory run
Use:
- `--all-ages` (or explicit `--day-whitelist ...` list)

#### EXP-10: Sex-stratified analysis
Run:
```bash
python3 scripts/stratify_by_sex.py \
  --predictions <control_pred.csv> <hls_pred.csv> \
  --output outputs/analysis/sex_stratified_rag.csv
```

#### EXP-11: Feature Distillation (Xception student, RETFound teacher)
Supported in `RETFoundLoRA/run.py` with:
- `--distill-teacher-ckpt`
- `--distill-alpha`
- `--distill-feature-only`
- `--skip-stress-eval` (optional control-only experiment)
